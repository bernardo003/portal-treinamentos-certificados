# Guia para gravar a demonstração do CertiForm

**Duração sugerida:** 2 a 3 minutos  
**Protótipo:** https://bernardo003.github.io/portal-treinamentos-certificados/  
**Curso demonstrativo:** Segurança do paciente e boas práticas assistenciais

## Preparação

- Abra o protótipo e use somente um nome fictício.
- Confirme que não aparecem dados de colegas, pacientes ou contas reais.
- Grave a janela do navegador ou a tela inteira, com áudio compreensível.
- Faça um teste para conferir se os textos e o cursor ficam visíveis.

## Sequência sugerida

1. **Abertura (0:00–0:15):** apresente o CertiForm como protótipo acadêmico de Educação Corporativa e RH, sem uso institucional.
2. **Formulário (0:15–0:45):** mostre o curso e o campo “Preencha seu nome”. Use um nome fictício e apresente as atividades.
3. **Bloqueio (0:45–1:00):** tente avançar sem concluir uma atividade e mostre a mensagem apresentada.
4. **Avaliação (1:00–1:35):** conclua as atividades, responda às questões e envie a avaliação.
5. **Certificado (1:35–2:05):** após aprovação, mostre o certificado e explique como imprimir ou salvar em PDF.
6. **Consulta (2:05–2:30):** consulte o código no mesmo navegador e explique o que a consulta demonstra.
7. **Limites (2:30–2:50):** diga que o código é local e que o protótipo ainda não tem backend ou integração com RH.

## Antes de entregar

- Grave o vídeo real; este documento é apenas o roteiro.
- Publique no local indicado pelo orientador, com acesso de visualização para o avaliador.
- Teste o link em uma janela sem login para confirmar as permissões.
- Não mostre RA, e-mail institucional, dados de pacientes ou dados clínicos.
